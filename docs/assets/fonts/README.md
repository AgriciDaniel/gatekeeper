# Fonts in the README art

`banner.svg`, `router.svg` and `rollup.svg` embed small subsets (only the glyphs used) of three fonts, so the art looks the same wherever GitHub renders it:

| Font | License | Source |
|---|---|---|
| Pixelify Sans | SIL Open Font License 1.1, [OFL-PixelifySans.txt](OFL-PixelifySans.txt) | https://github.com/eifetx/Pixelify-Sans |
| JetBrains Mono | SIL Open Font License 1.1, [OFL-JetBrainsMono.txt](OFL-JetBrainsMono.txt) | https://github.com/JetBrains/JetBrainsMono |
| Hanken Grotesk | SIL Open Font License 1.1, [OFL-HankenGrotesk.txt](OFL-HankenGrotesk.txt) | https://github.com/marcologous/hanken-grotesk |

The subsets were fetched from Google Fonts. The fonts are not sold on their own and keep their original names inside the license files; the embedded subsets use private family names (`GK Pixel`, `GK Mono`, `GK Body`), as the OFL asks for modified versions.
